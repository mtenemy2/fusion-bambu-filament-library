==============================================================
 Bambu Lab 필라멘트 라이브러리 for Autodesk Fusion
 사용 설명서 (한국어)
==============================================================

Bambu Lab 필라멘트 전 제품의 색상과 물성을 Fusion에 넣어 주는
스크립트입니다. 실행할 때마다 Bambu Lab 공식 데이터를 인터넷에서
받아, 새로 나온 필라멘트와 색상을 자동으로 추가합니다.


--------------------------------------------------------------
1. 무엇이 들어가나요
--------------------------------------------------------------

 [외관(Appearance)] 색상마다 1개
   - Bambu 공식 색상 코드(HEX)를 그대로 사용합니다.
   - 제품에 맞게 광택, 무광, 실크, 반투명, 메탈 질감을 적용합니다.
   - 이름 예: Bambu PLA Basic - Jade White (제이드 화이트) [10100]
     (대괄호 안 숫자는 Bambu 색상 코드)

 [물리 재질(Physical Material)] 제품 라인마다 1개
   - 이름 예: Bambu PLA Basic, Bambu PETG HF, Bambu TPU 95A HF
   - 밀도, 영률, 강도, 열 특성 값이 들어 있어 무게 계산과
     해석에 쓸 수 있습니다.
   - 재질 정보의 메모(Comments)에 권장 노즐/베드 온도,
     건조 조건, 데이터 출처가 적혀 있습니다.

 모든 항목은 Fusion "즐겨찾기(Favorites)"에 등록되어
 어떤 디자인에서든 바로 쓸 수 있습니다.

 포함 범위(2026년 11월 기준): PLA, PETG, ABS, ASA, TPU, PC,
 나일론(PA), PET-CF, PPS-CF, PVA, 서포트 / 342색, 48개 라인


--------------------------------------------------------------
2. 설치
--------------------------------------------------------------

 1) 압축을 풉니다. "BambuFilamentLibrary" 폴더가 나옵니다.

 2) 이 폴더를 통째로 아래 위치에 복사합니다.

    Windows:
      %APPDATA%\Autodesk\Autodesk Fusion 360\API\Scripts\
      (파일 탐색기 주소창에 위 경로를 붙여 넣고 Enter)

    Mac:
      ~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/Scripts/

    또는 Fusion에서 Shift+S → "스크립트 및 추가 기능" 창 →
    스크립트 옆 "+" 버튼 → 압축을 푼 폴더를 선택해도 됩니다.


--------------------------------------------------------------
3. 실행
--------------------------------------------------------------

 1) Fusion에서 Shift+S 를 누릅니다.
 2) 목록에서 "BambuFilamentLibrary"를 선택하고 실행(Run)을 누릅니다.
 3) 창이 뜨고 아래 내용을 보여 줍니다.
      - 데이터 출처 (online = 인터넷에서 최신 데이터를 받음)
      - 아직 즐겨찾기에 없는 색상 수
      - 이미 있는 색상 수
      - 값이 바뀐 항목 수
 4) "예(Yes)"를 누르면 새 디자인이 열리고, 없는 항목만 만들어
    즐겨찾기에 추가합니다.
      - 처음에는 전체를 만들므로 1~3분 걸립니다.
      - 진행 창이 끝날 때까지 기다려 주세요.
 5) 끝나면 열린 디자인을 "Bambu Filament Library" 같은 이름으로
    저장해 두면 참고용 원본이 됩니다. (저장하지 않아도 즐겨찾기에는
    이미 들어가 있습니다.)

 * 새 필라멘트가 나왔는지 궁금하면 다시 실행만 하면 됩니다.
   새로 나온 색상만 추가됩니다.
 * 인터넷이 안 되면 폴더에 들어 있는 데이터로 실행됩니다.


--------------------------------------------------------------
4. 사용법
--------------------------------------------------------------

 1) 바디를 마우스 오른쪽 버튼으로 클릭 → "물리 재질"
    → 즐겨찾기에서 "Bambu PLA Basic" 같은 재질을 지정합니다.
    (무게 계산, 해석용)

 2) 단축키 A (외관) → 즐겨찾기에서
    "Bambu PLA Basic - 원하는 색"을 바디에 끌어다 놓습니다.
    (화면에 보이는 색)

 * 재질은 제품 라인별로, 색은 색상별로 나뉘어 있습니다.
   Fusion은 외관을 재질 위에 덮어쓰는 방식이라 이렇게 쓰는 것이
   정상입니다. (Fusion API로는 재질에 색을 직접 연결할 수 없습니다.)


--------------------------------------------------------------
5. "값이 바뀐 항목"이 있다고 나올 때
--------------------------------------------------------------

 Fusion은 스크립트가 즐겨찾기 항목을 지우거나 덮어쓰지 못하게
 되어 있습니다. Bambu가 색상이나 물성을 바꾸면 직접 정리해야 합니다.

 1) 스크립트 폴더의 "last_report.txt"를 열어 목록을 확인합니다.
 2) Fusion 즐겨찾기에서 해당 항목을 오른쪽 클릭 → 즐겨찾기에서 제거
 3) 스크립트를 다시 실행하면 새 값으로 추가됩니다.


--------------------------------------------------------------
6. 설정 (선택 사항)
--------------------------------------------------------------

 BambuFilamentLibrary.py 파일 맨 위에서 바꿀 수 있습니다.
 (메모장으로 열어 수정 후 저장)

   ONLINE_UPDATE = True     실행할 때 최신 데이터 다운로드
   ADD_TO_FAVORITES = True  즐겨찾기에 추가
   FAMILIES = None          특정 계열만 넣기
                            예: FAMILIES = ("PLA", "PETG")
   TEST_MODE = False        True로 하면 샘플 몇 개만 생성


--------------------------------------------------------------
7. 데이터 출처와 한계
--------------------------------------------------------------

 - 색상: Bambu Studio 공식 색상표(filaments_color_codes.json)
 - 물성: Bambu Lab 공식 기술 데이터 시트(TDS) 35종
   - TDS가 없는 제품은 가장 비슷한 제품의 값을 사용합니다.
   - 처음 보는 새 제품은 이름으로 종류를 추정해 같은 계열 값을 씁니다.
   - 푸아송비, 열전도율, 비열, 열팽창계수와 PVA/서포트의 강도는
     Bambu가 공개하지 않아 일반적인 값(추정값)을 넣었습니다.
 - 그라데이션/멀티컬러 제품은 첫 번째 색만 들어갑니다.
 - 색상 코드는 화면용 근사치라 실제 필라멘트와 조금 다를 수 있습니다.
 - 물성 값은 Bambu 시험값이며 참고용입니다. 실제 출력물은
   프린터, 설정, 형상에 따라 달라집니다.
